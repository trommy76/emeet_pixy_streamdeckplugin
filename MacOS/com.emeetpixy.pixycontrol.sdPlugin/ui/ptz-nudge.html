Just the number -- don't type "pan:" or "zoom:" in front of it, that will fail. Leave it blank to use a default (3600 for Pan/Tilt, 5 for Zoom). These are rough starting points in raw uvc-util units, not degrees -- run uvc-util -V 0x328f:0x00c0 -S pan-tilt-abs (or zoom-abs) to see the camera's real range and step size, and adjust to taste. Add one of these per direction you want (e.g. one set to pan/increase for "right", another to pan/decrease for "left").
