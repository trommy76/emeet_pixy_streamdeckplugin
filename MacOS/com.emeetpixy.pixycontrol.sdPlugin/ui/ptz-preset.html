There's no known way to store a named preset on the camera itself, so this plugin remembers presets for you. With the default "Tap to Recall, Hold to Save" action, one button does both: quickly tap it to move the camera to the preset, or press and hold it (about half a second) while the camera is where you want it to capture that position instead. If you'd rather have two separate buttons, set one to "Save only" and another to "Recall only" for the same slot. Presets are shared across every button using this action, and stick around after Stream Deck restarts.

UVC target override

Vendor:product ID passed to uvc-util's -V flag. Only change this if you have more than one UVC camera and auto-detection targets the wrong one.
